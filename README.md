# 📍 GeoSwitch – Location & Time-Based Sound Profile Automation

**GeoSwitch** is an Android application designed to automate a smartphone's ringer mode based on geographical location and scheduled time. It helps users manage their phone's sound settings without manually switching between Silent, Vibrate, and Normal modes.

Whether you're attending a meeting, studying, working, or relaxing at home, GeoSwitch makes managing your phone's sound profile easier and more convenient.

## 🚀 Key Features

- **Location-Based Automation:** Automatically change the phone's ringer mode when entering or leaving predefined locations.
- **Time-Based Scheduling:** Configure specific times to switch between different sound profiles.
- **Automatic Sound Management:** Reduce the need for manually changing phone sound settings.
- **Convenience:** Automate sound preferences for different daily activities and environments.

## ⚙️ How It Works

1. The user configures location-based or time-based automation rules.
2. The application monitors the configured conditions.
3. When a specified location or scheduled time condition is met, the application triggers the corresponding action.
4. The phone's ringer mode is automatically updated according to the configured rule.
